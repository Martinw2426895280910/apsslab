# Laboratorio Schvarzstein — Web Applet & GitHub Distribution

Este repositorio contiene la landing page y el portal de pacientes interactivo de **Laboratorio Schvarzstein**.

## 📂 Contenido del Proyecto

1. **`lab-schvarzstein/`**: Carpeta lista para subir a GitHub como repositorio independiente o GitHub Pages:
   - `lab-schvarzstein/index.html`: La aplicación completa en un único archivo autocontenido (HTML5 + Tailwind CSS + JS interactivo).
   - `lab-schvarzstein/README.md`: Instrucciones paso a paso para subirlo a GitHub y publicarlo gratis en GitHub Pages.

2. **Aplicación React en tiempo real (Vite + TypeScript)**:
   - Visualizable y operable directamente en el entorno de desarrollo y preview de Google AI Studio.

---

## 🚀 Publicación Rápida en GitHub Pages

1. Descargá o copiá el archivo `lab-schvarzstein/index.html`.
2. Creá un repositorio en GitHub llamado `lab-schvarzstein`.
3. Subí el archivo `index.html`.
4. En **Settings > Pages**, seleccioná la rama `main` y hacé clic en **Save**.
5. ¡Listo! Tu web estará online en minutos con URL propia.
